# Visual Reference: Monochrome Color System

## Core Palette

### Ink

Used for meaning, content, and primary emphasis.

- Ink 950: `#0D0D0F`
- Ink 800: `#1A1A1C`
- Ink 600: `#5C5B5E`

### Graphite

Used for structure, headers, logo, dividers.

- Graphite 700: `#403F41`
- Graphite 600: `#4A494C`
- Graphite 400: `#8A898D`

### Paper

Used for reading surfaces and background.

- Paper 50: `#FFFFFF`
- Paper 100: `#F4F3F2`
- Paper 200: `#ECEBEC`

## Dark Theme Snapshot

- Background: `#403F41`
- Surfaces: `#2E2D30`
- Text: `#F2F2F2`
- Emphasis: `#0D0D0F`

Mood: graphite, quiet, editorial.

## Light Theme Snapshot

- Background: `#F4F3F2`
- Surfaces: `#FFFFFF`
- Text: `#1A1A1C`
- Emphasis: `#403F41`

Mood: ink on paper.

---

## DO

- Use tone-on-tone contrast
- Prefer spacing over borders
- Let typography carry hierarchy
- Use underline for interaction
- Keep UI visually quiet

---

## DON’T

- ❌ Introduce blue, green, or purple
- ❌ Use gradients or glow effects
- ❌ Use heavy shadows
- ❌ Use color-coded states
- ❌ Add decorative backgrounds

If it looks expressive, remove it.

---

## Visual Test

A page is correct if:

- Screenshots feel calm
- No single element draws attention by color alone
- Removing color would not break meaning

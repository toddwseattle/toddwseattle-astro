# Introduction to Software Engineering

A quiet sample deck for the new `slides` course-material type.

---

## What Software Engineering Covers

- Building software that is useful
- Building software that is maintainable
- Building software with other people

---

## Three Lenses

Look at software engineering through product, code, and team practice.

--

### Product

Start with the user problem and the outcome you are trying to improve.

--

### Code

Design for change, not only for first delivery.

--

### Team Practice

Shared habits are part of the architecture.

---

## A Small Workflow

```bash
npm install
npm run dev
npm run test
```

Use a simple loop: change, verify, reflect, repeat.

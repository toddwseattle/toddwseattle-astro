## 0-9

<a id="term-2g-3g"></a>**2G / 3G**: Second- and third-generation cellular network technologies. The original iPhone was 2G-only; iPhone 3G added faster 3G connectivity.

<a id="term-3d"></a>**3D**: Three-dimensional graphics or media. The timeline uses it in the context of richer smartphone gaming experiences, which relied on improving [GPU](#term-gpu), [CPU](#term-cpu), and [SoC](#term-soc) capabilities.

<a id="term-3gs-4s"></a>**3GS / 4S**: iPhone model names. The 3GS was Apple's 2009 iPhone; the 4S was the final iPhone launch associated with Steve Jobs.

<a id="term-10-k"></a>**10-K**: Annual report filed by a U.S. public company with the [SEC](#term-sec).

<a id="term-20-f"></a>**20-F**: Annual report filed with the [SEC](#term-sec) by certain foreign private issuers, such as Nokia.

## A

<a id="term-a4-a5"></a>**A4 / A5**: Apple-designed [SoC](#term-soc) families used in iPad and iPhone devices. The A4 was Apple's first major custom [ARM](#term-arm)-based SoC.

<a id="term-arm-cortex-cores"></a>**A7 / A8 / A9 / A15 / A53 / A57**: [ARM](#term-arm) Cortex processor core families. A7 emphasized efficiency, A8 and A9 moved smartphones toward richer computing experiences, A15 was a high-performance 32-bit core, and A53/A57 were early [ARMv8-A](#term-arm-versions) 64-bit Cortex cores.

<a id="term-a64"></a>**A64**: The 64-bit instruction set introduced with [ARMv8-A](#term-arm-versions).

<a id="term-aarch32-aarch64"></a>**AArch32 / AArch64**: [ARM](#term-arm) execution states. AArch32 supports 32-bit ARM code, while AArch64 supports 64-bit ARM code.

<a id="term-arm"></a>**ARM**: Originally "Acorn RISC Machine," later "Advanced RISC Machine." In this timeline, ARM refers to the processor architecture and licensing ecosystem that became dominant in mobile devices. See also [RISC](#term-risc), [SoC](#term-soc), and [ARM vs. Intel](#term-arm-vs-intel).

<a id="term-arm-vs-intel"></a>**ARM vs. Intel**: ARM and Intel represented different architectural and business assumptions during the smartphone transition. ARM used a [RISC](#term-risc) architecture and licensed designs to many chipmakers, which made it easier for companies such as Qualcomm, Samsung, and Apple to build power-efficient mobile [SoCs](#term-soc). Intel's dominant [x86](#term-x86) business was built around [CISC](#term-cisc) compatibility, high-performance PC/server processors, and manufacturing its own chips. That model was extremely strong in [PCs](#term-pc) but harder to adapt quickly to phone constraints: low power, integrated modems, small thermal envelopes, and rapid handset design cycles.

<a id="term-arm7-arm7tdmi"></a>**ARM7 / ARM7TDMI**: Early [ARM](#term-arm) processor core family and a widely licensed core that helped make low-power feature phones practical.

<a id="term-arm11-arm1176jzf-s"></a>**ARM11 / ARM1176JZF-S**: [ARM](#term-arm) processor core family and specific core used in the original iPhone generation.

<a id="term-arm926ej-s"></a>**ARM926EJ-S**: ARM9-family processor core with features such as an [MMU](#term-mmu) and Java acceleration.

<a id="term-arm-versions"></a>**ARMv5TEJ / ARMv6 / ARMv7 / ARMv8-A**: Generations of the [ARM](#term-arm) instruction set architecture. The timeline uses them to show ARM's progression from embedded and feature-phone workloads toward full smartphone and PC-class computing.

<a id="term-att"></a>**AT&T**: American Telephone and Telegraph, the U.S. carrier that had the original iPhone exclusivity deal.

## B

<a id="term-bb10"></a>**BB10**: BlackBerry 10, BlackBerry's late modern smartphone [OS](#term-os).

<a id="term-big-little"></a>**big.LITTLE**: [ARM](#term-arm)'s heterogeneous multiprocessing design that pairs high-performance and low-power [CPU](#term-cpu) cores so devices can balance speed and battery life.

## C

<a id="term-cdma"></a>**CDMA**: Code Division Multiple Access, a cellular network technology used by carriers such as Verizon and by Qualcomm modem platforms. See also [WCDMA](#term-wcdma).

<a id="term-cc-by-sa"></a>**CC BY-SA**: Creative Commons Attribution-ShareAlike, a license that allows reuse with attribution and similar-share terms.

<a id="term-ceo"></a>**CEO**: Chief Executive Officer, the senior executive responsible for overall company direction.

<a id="term-cik"></a>**CIK**: Central Index Key, the [SEC](#term-sec) identifier for a company or filing entity.

<a id="term-cisc"></a>**CISC**: Complex Instruction Set Computer. CISC architectures, including Intel's [x86](#term-x86) family, provide many instructions, some of which can perform complex operations. This helped preserve software compatibility across decades of [PC](#term-pc) evolution, but the instruction set and compatibility burden made x86 chips more difficult to optimize for the extreme power and integration constraints of early smartphones. Contrast with [RISC](#term-risc).

<a id="term-cnbc"></a>**CNBC**: Consumer News and Business Channel, the business news network where Steve Ballmer publicly dismissed the iPhone.

<a id="term-cpu"></a>**CPU**: Central Processing Unit, the general-purpose processor that runs program instructions. In smartphones, the CPU is one part of a broader [SoC](#term-soc).

## D

<a id="term-dsp"></a>**DSP**: Digital Signal Processor, a processor optimized for signal-processing tasks such as audio, video, and wireless communication. DSPs are often integrated into mobile [SoCs](#term-soc).

## E

<a id="term-edgar"></a>**EDGAR**: Electronic Data Gathering, Analysis, and Retrieval system, the [SEC](#term-sec)'s public filing database.

## F

<a id="term-fcc"></a>**FCC**: Federal Communications Commission, the U.S. regulator for communications, spectrum, and related approvals.

<a id="term-fy"></a>**FY**: Fiscal Year, a company's accounting year. Public-company discussions often pair FY with filings such as [10-K](#term-10-k) or [20-F](#term-20-f).

## G

<a id="term-g1"></a>**G1**: T-Mobile G1, the consumer name for the HTC Dream, the first commercial Android phone.

<a id="term-gps"></a>**GPS**: Global Positioning System, satellite-based location technology that enabled services such as ride hailing and turn-by-turn navigation.

<a id="term-gpu"></a>**GPU**: Graphics Processing Unit, a processor optimized for graphics and parallel workloads. In smartphones, GPUs are typically integrated into [SoCs](#term-soc).

<a id="term-gsm"></a>**GSM**: Global System for Mobile Communications, a cellular standard that helped Europe standardize mobile networks across borders.

<a id="term-gsma"></a>**GSMA**: GSM Association, the mobile industry trade association.

## H

<a id="term-hp"></a>**HP**: Hewlett-Packard, the company that acquired Palm and later discontinued [webOS](#term-webos) hardware such as the TouchPad.

<a id="term-htc"></a>**HTC**: High Tech Computer Corporation, the manufacturer of the HTC Dream, the first commercial Android phone.

## I

<a id="term-idc"></a>**IDC**: International Data Corporation, a market research firm cited for device shipment data.

<a id="term-ios"></a>**iOS**: Apple's mobile [OS](#term-os) for iPhone and iPad.

<a id="term-iot"></a>**IoT**: Internet of Things, networked embedded devices and sensors beyond traditional computers and phones. Many IoT devices use low-power [ARM](#term-arm)-based chips.

## M

<a id="term-m1"></a>**M1**: Apple's 2020 [ARM](#term-arm)-based Mac processor family, referenced as an endpoint for Apple's custom silicon trajectory.

<a id="term-ma"></a>**M&A**: Mergers and Acquisitions, the buying, selling, and combining of companies.

<a id="term-mms"></a>**MMS**: Multimedia Messaging Service, a mobile messaging standard for sending media such as images and video. See also [SMS](#term-sms).

<a id="term-mmu"></a>**MMU**: Memory Management Unit, hardware that supports virtual memory and helps full [operating systems](#term-os) run reliably.

<a id="term-msm7201a"></a>**MSM7201A**: Qualcomm mobile chipset used in early Android hardware such as the HTC Dream.

## N

<a id="term-n97-x6"></a>**N97 / X6**: Nokia touchscreen smartphone models used as examples of Symbian-era response to iPhone and Android.

<a id="term-neon"></a>**NEON**: [ARM](#term-arm)'s [SIMD](#term-simd) instruction set extension for media and signal-processing workloads.

## O

<a id="term-oem"></a>**OEM**: Original Equipment Manufacturer. In this timeline, OEMs are handset makers that built phones using platforms such as Android or Windows Mobile.

<a id="term-omap3-omap4"></a>**OMAP3 / OMAP4**: Texas Instruments "Open Multimedia Applications Platform" mobile processor families used in smartphones and embedded devices.

<a id="term-os"></a>**OS**: Operating System, the software layer that manages hardware and provides services for applications.

## P

<a id="term-pa-semi"></a>**P.A. Semi**: Palo Alto Semiconductor, a chip design company Apple acquired before its custom silicon efforts accelerated.

<a id="term-pc"></a>**PC**: Personal Computer. The timeline uses PC comparisons to show when phones and tablets began competing with traditional desktop and laptop computing.

<a id="term-pdf"></a>**PDF**: Portable Document Format, a document file format used for some source materials linked from the timeline.

<a id="term-pmi"></a>**PMI**: Project Management Institute, cited in the timeline for a DynaTAC case study.

## Q

<a id="term-qsd8250"></a>**QSD8250**: Qualcomm Snapdragon chipset that combined an [ARM](#term-arm)-based [CPU](#term-cpu) with modem and multimedia hardware.

## R

<a id="term-razr-v3"></a>**RAZR / V3**: Motorola's stylized product name and model shorthand for its thin clamshell phone line.

<a id="term-rd"></a>**R&D**: Research and Development, the investment activity used to create new technologies and products.

<a id="term-rf"></a>**RF**: Radio Frequency, the radio signal domain used in wireless communication systems.

<a id="term-rim"></a>**RIM**: Research In Motion, the original company name behind BlackBerry.

<a id="term-risc"></a>**RISC**: Reduced Instruction Set Computer. RISC architectures use a smaller, more regular instruction set, which can simplify processor design and improve power efficiency. [ARM](#term-arm)'s RISC approach fit mobile phones well because handset makers needed efficient chips that could run all day on batteries and be integrated into compact [SoCs](#term-soc). Contrast with [CISC](#term-cisc).

## S

<a id="term-s-1"></a>**S-1**: [SEC](#term-sec) registration statement used by companies preparing for an initial public offering.

<a id="term-s-iii"></a>**S III**: Samsung Galaxy S III, an Android flagship associated with Android's 2012 market-share growth.

<a id="term-sdk"></a>**SDK**: Software Development Kit, the tools and documentation developers use to build software for a platform.

<a id="term-sec"></a>**SEC**: Securities and Exchange Commission, the U.S. agency that regulates public company disclosures and securities markets. See also [EDGAR](#term-edgar), [10-K](#term-10-k), [20-F](#term-20-f), and [S-1](#term-s-1).

<a id="term-simd"></a>**SIMD**: Single Instruction, Multiple Data. A processor technique for applying one instruction across multiple pieces of data at the same time, useful for media processing. See also [NEON](#term-neon).

<a id="term-sms"></a>**SMS**: Short Message Service, the text messaging standard that became a major feature-phone-era application. See also [MMS](#term-mms).

<a id="term-soc"></a>**SoC**: System on Chip. A chip that integrates multiple functions, such as [CPU](#term-cpu), [GPU](#term-gpu), modem, and [DSP](#term-dsp), into one package. SoC integration was central to the mobile advantage of [ARM](#term-arm)-based designs.

## T

<a id="term-ti"></a>**TI**: Texas Instruments, a semiconductor company whose OMAP chips appeared in mobile and embedded devices.

## U

<a id="term-ui"></a>**UI**: User Interface, the visible controls and interaction surfaces people use to operate software. See also [UX](#term-ux).

<a id="term-ux"></a>**UX**: User Experience, the design and interaction quality of a product from the user's perspective. See also [UI](#term-ui).

## V

<a id="term-vc"></a>**VC**: Venture Capitalist, an investor in early-stage companies.

<a id="term-vfp"></a>**VFP**: Vector Floating Point, [ARM](#term-arm) floating-point hardware used for faster numeric computation.

<a id="term-vp-210"></a>**VP-210**: Kyocera Visual Phone VP-210, an early commercial camera phone.

## W

<a id="term-wcdma"></a>**WCDMA**: Wideband Code Division Multiple Access, a 3G cellular technology related to UMTS networks. See also [CDMA](#term-cdma).

<a id="term-webos"></a>**webOS**: Palm's mobile [OS](#term-os), known for card-based multitasking and gesture navigation.

<a id="term-wm"></a>**WM**: Windows Mobile, Microsoft's pre-Windows Phone mobile [OS](#term-os).

## X

<a id="term-x86"></a>**x86**: Intel/AMD processor architecture dominant in [PCs](#term-pc) and servers during the smartphone disruption period. In this glossary, x86 is the main [CISC](#term-cisc) contrast to [ARM](#term-arm)'s [RISC](#term-risc) mobile trajectory.

## Z

<a id="term-z10"></a>**Z10**: BlackBerry Z10, BlackBerry's modern touchscreen [BB10](#term-bb10) device.

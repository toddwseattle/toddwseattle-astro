I joined Microsoft after undergrad as a Program Manager in the tools group. I was responsible for the release of [MASM 5.1](https://en.wikipedia.org/wiki/Microsoft_Macro_Assembler), [Microsoft C 6.0](https://en.wikipedia.org/wiki/Microsoft_Visual_C%2B%2B), as well as working with the other languages products on shared development tools. I wrote some of the first user interface specs for Developer Tools at Microsoft, specifically for [CodeView 3.0](https://en.wikipedia.org/wiki/CodeView) (most of the conventions we defined for data structure debugging are mimicked by debuggers today), the [Programmer's Workbench](https://en.wikipedia.org/wiki/Microsoft_Visual_C%2B%2B)--an early professional developer environment, and worked closely with the author of the ['Z' editor to release as 'M'](https://www.os2museum.com/wp/microsoft-editor/).

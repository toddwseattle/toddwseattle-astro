## Astro Architecture Notes

### Component Structure

```
src/pages/writing/[slug].astro    ← Dynamic route with getStaticPaths()
  ├── Frontmatter (build-time)
  │   ├── import { Image } from 'astro:assets'
  │   ├── getCollection('blog')   ← Type-safe query
  │   └── post.render()            ← Typed Content component
  └── Template (SSR)
      └── Conditional hero image render
```

### Type Flow

```
Content Collection Schema (Zod)
  ↓
Runtime Validation (build-time)
  ↓
TypeScript Types (CollectionEntry<'blog'>)
  ↓
Component Props (type-safe destructuring)
  ↓
Template Rendering (type-checked)
```

### Image Optimization Flow

```
ESM Import (src/assets/images/profile.jpg)
  ↓
Type Inference (ImageMetadata)
  ↓
Astro Image Component
  ↓
Build-time Optimization
  ↓
Multiple Format Generation (WebP, AVIF, fallback)
  ↓
Responsive Srcset
  ↓
Optimized Output (dist/_astro/)
```
